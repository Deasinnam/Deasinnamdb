## 대신남 스피드미터 — 운전이 비행이 되는 계기판

차량용 스피드미터를 비행기 계기판(PFD)처럼 보여 주는 앱입니다. 출발하면 활주로를 달려 이륙하고, 도착하면 착륙합니다.

### 내려받기
- **DaesinnamSpeedometer.apk** — 내 음악 + YouTube Music·Spotify 같은 외부 앱 소리 가져오기(곡 정보·재생 조작은 알림 접근 권한 필요)

설치한 뒤에는 앱 위 도구 줄의 **📖 초기 세팅 방법**을 눌러 GPS·스킨·수평 맞춤·알림 접근 설정을 그림으로 따라 하세요.

### 주요 기능
- 에어라인 스킨: 손그림풍 하늘·구름·바다 풍경 위 활주로, 새벽·한낮·노을·밤과 실제 해에 맞춘 자동 전환
- 카본·네온·아날로그 등 계기판 디자인을 스피드미터 고르기에서 바로 바꿈
- 과속 카메라 500m 앞부터 경고음과 남은 거리
- 착륙하면 평균 속도·운전 평점
- 재생 중인 노래 제목, 누적 주행거리·엔진오일 교체 거리
- 야간 화면 밝기 자동, 폴드 세로·반 화면 대응
