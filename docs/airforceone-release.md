## 에어포스원 — 운전이 비행이 되는 계기판

차량용 스피드미터를 비행기 계기판(PFD)처럼 보여 주는 앱입니다. 출발하면 활주로를 달려 이륙하고, 도착하면 착륙합니다.

### 내려받기
- **AirForceOne-full.apk (풀버전)** — 내 음악 + YouTube Music·Spotify 같은 외부 앱 소리 가져오기(곡 정보·재생 조작은 알림 접근 권한 필요)
- **AirForceOne-lite.apk (라이트)** — 내 음악만. 알림 접근 권한 없이 가볍게

두 판은 같은 앱(com.daesinnam.airforceone)이라 하나만 설치하세요.

### 주요 기능
- 3D 맵 스킨: 실제 지도(OpenStreetMap)와 고도로 만든 3D 풍경 위를 비행
- 지브리풍 하늘·구름·바다 풍경, 새벽·한낮·노을·밤과 실제 해에 맞춘 자동 전환
- 과속 카메라 500m 앞부터 경고음과 남은 거리
- 착륙하면 평균 속도·운전 평점
- 재생 중인 노래 제목, 누적 주행거리·엔진오일 교체 거리
- 야간 화면 밝기 자동, 폴드 세로·반 화면 대응
