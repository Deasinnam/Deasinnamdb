덜누름 PC 런처

모니터 연결 안 됨

USB-C 케이블(또는 허브)로 모니터를 꽂아 주세요.

모니터에 PC 화면 열림

처음 한 번 준비

  1. 휴대폰 화면 출력

    USB-C로 모니터를 꽂았을 때 폰 화면이 모니터에 나오면 지원하는 휴대폰이에요. 아무것도 안 나오면 이 휴대폰은 유선 화면 출력이 없어 무선 미러링만 가능해요(덜누름 PC 런처를 쓸 수 없어요).

  2. 데스크톱 모드 켜기

    모니터를 폰과 따로 쓰는 화면으로 만들고, 다른 앱도 모니터에서 창으로 열리게 하는 안드로이드 개발자 옵션이에요. 켠 뒤 휴대폰을 다시 시작해야 적용돼요.

    직접 켜는 방법
    1. 설정 › 휴대전화 정보 › (소프트웨어 정보) › 빌드 번호를 7번 눌러 개발자 옵션을 켜요. 휴대전화 정보 열기
    2. 설정 › 개발자 옵션에서 보조 디스플레이에서 데스크톱 모드 강제 사용(Force desktop mode)을 켜요.
    3. 같은 곳의 자유 형식 창 사용(Enable freeform windows)도 켜요.
    4. 휴대폰을 다시 시작해요.

    메뉴 이름은 제조사 · 안드로이드 버전에 따라 조금 달라요. 일부 제조사는 이 메뉴를 숨겨 두어, 그런 휴대폰은 PC 화면은 모니터에 열려도 다른 앱이 폰에서 열릴 수 있어요. 픽셀 · 삼성 최신 기기는 안드로이드 16의 데스크톱 기능이 기본으로 들어 있어 이 단계가 필요 없을 수 있어요.

  3. 터치패드 · 폰 키보드

    마우스가 없을 때 폰 화면을 터치패드로 써서 모니터의 포인터를 움직이고, 폰 키보드로 글자를 넣어요. 접근성에서 덜누름 PC 런처 터치패드를 켜 주세요. 화면 내용을 저장하거나 밖으로 보내지 않아요.

  4. 꽂으면 바로 열기

    모니터를 꽂으면 PC 화면을 모니터에 저절로 열어요. 알림에 "모니터 연결" 표시가 계속 떠 있어요.

알아 두면 좋아요
  • 블루투스 · USB 마우스와 키보드를 연결하면 모니터에서 그대로 쓸 수 있어요. 키보드 ⊞(윈도우 키)로 시작 메뉴, ⊞+D로 바탕화면.
  • 모니터의 PC 화면은 바탕화면 · 작업 표시줄 · 시작 메뉴 · 창 · 위젯을 덜누름 데스크와 똑같이 써요.
  • 충전하면서 쓰려면 충전 단자(PD)가 있는 USB-C 허브를 쓰세요.
