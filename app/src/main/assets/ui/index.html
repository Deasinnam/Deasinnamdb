키 매핑

게임패드·키보드 버튼을 누르면 게임 화면의 정해 둔 자리를 대신 눌러 줘요. 패드를 지원하지 않는 게임도 패드로 할 수 있어요.

  1. 아래에서 키 매핑 권한 켜기 → 설정의 "덜누름 게임 키 매핑"을 켜요
  2. 게임을 길게 눌러 이 게임에서 키 매핑 쓰기를 켜요
  3. 게임 화면 왼쪽 위 🎮 단추 → 빈 곳을 눌러 자리를 정하고 패드 버튼을 누르면 연결돼요

표시를 짧게 누르면 톡(한 번) / 꾹(누르는 동안) 바뀌고, 길게 누르면 지워져요. 아날로그 스틱과 두 버튼 동시 누르기는 다음 업데이트예요.

    • 스냅드래곤 칩 기기(갤럭시 Z 폴드7 · 폴드8 울트라 등)에서 동작해요.

    • DroidDeck은 다른 개발팀의 무료 앱이에요. 덜누름은 공식 배포처로 안내하고 실행만 해요.
