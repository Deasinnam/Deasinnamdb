원작에서 바꾼 것

Apache License 2.0 제4조에 따라, 덜누름 워크가 원작을 고친 내용을 알립니다.

  • 공통: 데스크톱·웹 프로그램을 안드로이드 WebView 안에서 돌도록 감싸고, 저장·열기·공유를 안드로이드 방식(파일 만들기·파일 고르기)으로 바꿨습니다. 제품 이름·아이콘·시작 화면 문구를 덜누름 워크 것으로 바꿨습니다.
  • 문서 편집(IeumOffice): Electron 대신 앱 안의 Node.js에서 데스크톱 메인 코드를 돌리는 호스트를 더했고, 편집기 화면이 쓰는 자체 프로토콜 주소·CSP를 앱 주소로 바꿨으며, 엑셀 엔진(xlsx-sidecar)을 안드로이드용으로 컴파일했습니다. 편집기 안에 표시되는 제품 이름을 바꿨습니다.
  • 사진 편집(PhotoCraft): 공식 웹 빌드를 그대로 쓰고, 로딩 문구만 바꿨습니다.
  • 동영상 편집(FilmCraft): 소스에서 직접 빌드하면서, 웹(wasm)에서 H.264 내보내기가 스레드 풀을 만들지 못해 실패하던 부분을 고쳤습니다 (웹에서는 스레드 풀 없이 인코딩). 로딩 문구를 바꿨습니다.

상표

덜누름 워크는 pblsketch, Mainfunc, Inc., ArtCraft 팀(storytold)과 관련이 없으며 그들의 후원이나 보증을 받지 않았습니다. "IeumOffice", "이음오피스", "GenOffice", "PhotoCraft", "FilmCraft", "ArtCraft"는 각 소유자의 이름이며, 위 표에서는 출처를 밝히려는 목적으로만 씁니다. 편집기 안의 일부 메뉴·안내 문구에는 원작 이름이 그대로 남아 있을 수 있습니다. Microsoft, Word, Excel, PowerPoint, 한글, HWP, Adobe, Photoshop 등은 각 회사의 상표이며, 여는 파일 형식을 설명하는 데만 씁니다.
