# Daesinnam Amp (안드로이드 앱)

레트로 스킨 MP3 플레이어. LED 스펙트럼, 10밴드 EQ, 플레이리스트, 스킨 6종, 화면 크기별 자동 배치(1열/2열/가로 한 줄), 알림창 재생 조작, 백그라운드 재생을 지원합니다.

**외부 앱 연동**: YouTube Music, Spotify 등 다른 앱으로 음악을 들을 때도 곡 정보, 재생 조작, 사운드 시각화, EQ를 사용할 수 있습니다. 상단의 [외부 앱]을 누르고 안내에 따라 알림 접근과 오디오 분석 권한을 허용하세요.
Android 8.0 이상 태블릿·휴대폰에서 동작합니다.

## 차량 핸들 버튼 · 삼성 DeX

내 음악을 재생하면 안드로이드 미디어 세션이 열려, 블루투스로 연결된 차량의 핸들 버튼(다음/이전/재생/일시정지), 블루투스 이어폰, 키보드 미디어 키로 조작할 수 있고 차량 화면에 곡 제목과 앨범 아트가 표시됩니다. 외부 앱 모드에서는 핸들 버튼이 YouTube Music·Spotify로 바로 전달됩니다. DeX로 외부 디스플레이에 띄워도 창 크기에 맞춰 배치가 바뀝니다.

## 두 가지 판

- **DaesinnamAmp.apk (권장)**: 일반 설치용. 외부 앱 연동은 시각화, EQ, 재생/다음/이전 버튼, Spotify 곡 정보(Spotify 설정 → 기기 브로드캐스트 상태 켜기)를 지원합니다.
- **DaesinnamAmp-full.apk**: 알림 접근 권한으로 모든 앱의 곡 정보, 앨범 아트, 탐색까지 지원합니다. 이 권한 때문에 Google Play 프로텍트가 설치를 막을 수 있습니다.

두 판은 같은 앱이라 서로 덮어 설치됩니다.

## APK 만드는 방법 1: GitHub (PC에 아무것도 설치하지 않음)

1. github.com 에 로그인하고 새 저장소(New repository)를 만듭니다. 비공개(Private)여도 됩니다.
2. 저장소 화면에서 **Add file → Upload files**를 누르고, 이 압축을 푼 폴더 안의 **모든 파일과 폴더**를 끌어다 놓은 뒤 **Commit changes**를 누릅니다.
   - `.github` 폴더가 꼭 함께 올라가야 합니다. 숨김 폴더라 안 보이면 파일 탐색기에서 숨김 항목 표시를 켜세요.
3. 저장소의 **Actions** 탭으로 가면 "Build APK"가 자동으로 실행됩니다. 5분 정도 걸립니다.
4. 초록색 체크가 뜨면 그 실행을 눌러 맨 아래 **Artifacts**의 `DaesinnamAmp-apk`를 내려받습니다.
5. 받은 zip 안의 `app-release.apk`를 태블릿으로 옮깁니다.

## APK 만드는 방법 2: Android Studio

1. Android Studio에서 **Open**으로 이 폴더를 엽니다.
2. 메뉴 **Build → Build App Bundle(s) / APK(s) → Build APK(s)**를 누릅니다.
3. `app/build/outputs/apk/` 폴더에 APK가 생깁니다.

## 태블릿에 설치

1. APK 파일을 태블릿에서 엽니다.
2. "출처를 알 수 없는 앱" 경고가 뜨면 **설정 → 이 출처 허용**을 켭니다.
3. 설치 후 알림 권한을 허용하면 알림창과 잠금 화면에서 이전/재생/다음 버튼을 쓸 수 있습니다.

## 참고

- 음악은 **+ 추가** 버튼으로 기기의 파일을 여러 개 한 번에 고릅니다.
- 재생 중에 뒤로 가기를 눌러도 앱이 꺼지지 않고 음악이 계속 나옵니다. 완전히 끄려면 정지 후 뒤로 가기를 누르세요.
- APK는 `signing/amp.keystore`로 서명되어 업데이트 때 덮어 설치됩니다. 저장소가 공개라 이 키도 공개 상태이니, 이 저장소의 Releases가 아닌 곳에서 받은 Daesinnam Amp는 설치하지 마세요. Play 스토어에 올리려면 별도의 비공개 키가 필요합니다.
- 화면 디자인은 `app/src/main/assets/index.html` 한 파일에 들어 있습니다.
