# 덜누름 덱스 (com.daesinnam.dex)

DeX를 지원하지 않는 일반 안드로이드 태블릿(레노버 · 샤오미 · 원플러스 등)에서 덱스처럼 쓰는 데스크톱 홈 앱.

- 바탕화면 아이콘 · 아래 작업 표시줄(고정 앱 + 열린 창) · 앱 서랍(검색) · 시계 · 배터리 · 와이파이
- 앱 메뉴(오른쪽 클릭/길게 누르기): 창으로 · 전체 화면 · 왼쪽/오른쪽 절반 · 모니터에서 열기 · 고정 · 앱 정보 · 제거
- 외부 모니터(USB-C DP Alt)를 연결하면 모니터에 덱스 화면이 따로 뜸 (SECONDARY_HOME)
- 덱스 설정: Shizuku 연결 시 자유 창 · 모니터 데스크톱 모드를 앱에서 바로 켬, 없으면 개발자 옵션 안내
- 인터넷 권한 없음

## 빌드
`deolnureum-dex` 가지에 올리면 GitHub Actions가 APK를 빌드하고 에뮬레이터(태블릿 크기 + 자유 창 + 가짜 모니터)로 점검한 뒤
미리보기 릴리스 `dex-preview`(APK) · `dex-ci`(점검 기록)에 올립니다. 사이트에는 올리지 않습니다.
