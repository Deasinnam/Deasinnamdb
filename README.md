# Daesinnam Amp (안드로이드 앱)

레트로 스킨 MP3 플레이어. LED 스펙트럼, 10밴드 EQ, 플레이리스트, 스킨 6종, 화면 크기별 자동 배치(1열/2열/가로 한 줄), 알림창 재생 조작, 백그라운드 재생을 지원합니다.

**외부 앱 연동**: YouTube Music, Spotify 등 다른 앱으로 음악을 들을 때도 곡 정보, 재생 조작, 사운드 시각화, EQ를 사용할 수 있습니다. 상단의 [외부 앱]을 누르고 안내에 따라 알림 접근과 오디오 분석 권한을 허용하세요.
Android 8.0 이상 태블릿·휴대폰에서 동작합니다.

## 플레이리스트 · 차 연결 · 간편 모드

- **플레이리스트 저장**: [+ 추가]로 파일을, [+ 폴더]로 폴더 전체를 고르면 목록이 저장되어 앱을 다시 켜도 남고, 마지막 곡과 위치부터 이어서 들을 수 있습니다.
- **차 연결 시 이어서 재생**: 설정 → 차량 연결에서 켭니다. 특정 차만 지정할 수 있고, "다른 앱 위에 표시"를 허용하면 앱이 꺼져 있어도 차에 타면 자동으로 열립니다(허용하지 않으면 알림을 눌러 시작).
- **주행 중 간편 모드**: 큰 버튼만 있는 화면. 상단 [간편 모드]로 켜거나, 차 연결·시속 10km 이상에서 자동으로 켜지게 할 수 있습니다.
- **핸들 버튼 · 차량 화면**: 저장된 곡은 안드로이드 표준 플레이어(Media3 ExoPlayer)가 재생해서, 핸들·블루투스 이어폰 버튼, 차량 화면 곡 정보, 잠금 화면, 오디오 포커스를 표준 방식으로 처리합니다. 앱이 꺼져 있어도 핸들의 재생 버튼으로 마지막 곡부터 이어서 재생됩니다. 시각화와 EQ는 플레이어 소리를 직접 분석·처리해 마이크 권한 없이 동작합니다.

## 자동차 스킨 · 지도

자동차 스킨은 **대신남 자동차 모드**(구리색), **대신남 자동차 모드 · 콕핏**(비행기 조종석 계기판을 조종 콘솔과 같은 무광 올리브·연두색으로 통일, 상단 로고는 D1 "DAESINNAM ONE · AIR FORCE" 이미지), **대신남 드라이브**(블루, 대신남 로고) 세 가지입니다. 콕핏 스킨은 나사로 고정된 회색 계기판, 각인 명판, 검은 글래스 디스플레이, 켜지면 초록 불이 들어오는 조명 버튼, 스로틀 레버 모양 EQ 손잡이를 씁니다. 이 스킨을 고르면 속도계가 **콕핏 PFD**로 바뀝니다. 왼쪽 속도 테이프, 가운데 자세계(선회하면 기울고 가속하면 기수가 듦), 오른쪽 고도 테이프, 위쪽 GPS·진행 방향·경고 속도 표시줄로 구성됩니다. 진행 방향은 기기의 나침반(방향 센서)으로 정하고, 방향을 틀면 하늘과 구름이 옆으로 흘러 비행기가 선회하는 것처럼 보입니다. 폰이나 차량이 기울면 자세계도 같이 기울고(처음 자세를 수평으로 삼으며, "수평 맞춤"으로 다시 맞출 수 있음), 하늘에는 구름이 앞에서 다가와 지나가며 속도가 빠를수록 빨리 지나갑니다. "하늘"을 야간(또는 자동: 오후 7시~오전 6시)으로 하면 하늘이 어두워지고 달과 별이 뜨며 구름도 어둡게 바뀝니다. 콕핏 스킨에서는 최고 속도·주행 거리 같은 주행 정보가 속도계 위에 한 줄로 늘어서고, 속도계는 창 너비를 가득 채워 크게 표시됩니다. 속도계 창 제목줄의 ↕ 버튼(창 크기 조절)을 켠 동안에만 창 아래 손잡이가 나타나 높이를 바꿀 수 있습니다(화면을 스크롤하다 실수로 바뀌지 않게, 15초 동안 조절하지 않으면 자동으로 꺼짐). 높이를 바꾸면 PFD도 그 크기와 비율에 맞춰 다시 그려집니다. 콕핏 스킨에서는 속도계 창만 높이를 조절할 수 있고, 나머지 창은 내용에 맞는 높이로 고정됩니다(다른 스킨에서 정해 둔 높이는 그 스킨에서 그대로 유지).

콕핏 스킨에는 창이 두 개 더 있습니다.
- **COCKPIT CONTROL**: "대신남 원 Cockpit Control" 디자인 패키지를 예전 조종 패널 높이로 줄여 이식한 전투기 보조 제어 콘솔(제목은 한글 "미디어 볼륨·와이파이·블루투스·간편 모드"와 영문 "EMERGENCY", 안내 문구 없이 최소 높이, MUTE는 + 옆, SOS 덮개는 노랑·검정 경고 커버, 폰에서는 SOS가 가운데 줄)(무광 올리브 금속, 각인 라벨, 은색 레버, 회전식 볼륨 노브, 적갈색 보호 덮개). 순서는 MASTER VOL → DATA LINK → EMERGENCY → COMMS → DRIVE MODE. 볼륨은 노브 드래그·슬라이더·+/−·음소거로 실제 미디어 볼륨을 바꾸고 기기에서 다시 읽은 값을 표시합니다. 와이파이·블루투스 레버는 기기에서 읽은 실제 상태만 표시하며(읽을 수 없으면 CHECK STATE), 앱이 직접 바꿀 수 없으면 시스템 설정을 엽니다. EMERGENCY는 덮개를 연 뒤에만 SOS를 누를 수 있고(10초 미조작·화면 이탈·접기 시 닫힘), 누르면 등록한 연락처로 바로 전화합니다. 연락처는 콘솔의 설정(톱니바퀴) 또는 앱 설정 → SOS 긴급 연락처 어디서 바꿔도 같습니다. DRIVE MODE는 앱의 간편 모드를 켜고 끕니다(차량 주행 기능 아님).
- **TOWER**: 두 줄 높이의 작은 창입니다. 콕핏 스킨을 켤 때마다 관제탑이 출발 전 점검(안전벨트, 브레이크, 미러, 연료, 조명, GPS 수신, 오디오, 경로)을 무전처럼 두 줄씩 바꿔 가며 띄우고, 끝나면 문구가 사라지고 "CLEARED FOR TAKEOFF"와 함께 이륙 허가 효과음(무전·차임·엔진 소리)과 음성 안내가 나옵니다. "다시 점검", "건너뛰기"로 다시 듣거나 넘길 수 있습니다. 주행 중 속도가 50·100·120·150·180·200km/h에 처음 도달하면 관제탑 창에 빨간 글자로 "속도 주의"가 6초간 뜹니다(그보다 5km/h 아래로 내려가면 다시 경고). 속도계 아래 **NAVIGATION** 창은 처음에 사용 여부를 묻고, 사용하면 GPS 위치를 지도에 표시하며, **TMAP 켜기**(TMAP으로 전환), **TMAP 하단에 켜기**(TMAP을 화면 아래쪽에 띄워 대신남 AMP와 위아래로 반씩 나눠 봄, 가운데 막대로 크기 조절), **TMAP 옆 창**(DeX·분할 화면에서 옆에 띄움)을 쓸 수 있습니다. 분할 화면에서 위아래로 나뉘는 것은 세로 화면일 때이며, 가로 화면에서는 안드로이드가 오른쪽에 붙입니다(DeX·자유 창에서는 아래쪽 절반 크기로 엶). 기본 지도는 OpenStreetMap이고, "지도 종류 · 키"에서 네이버 지도(Client ID), 카카오맵(JavaScript 키), TMAP 지도(앱 키)를 고를 수 있습니다. 네이버·카카오는 키를 만들 때 웹 주소로 `https://appassets.androidplatform.net`을 등록해야 합니다. 사용하지 않으면 창이 접혀 맨 아래로 내려갑니다.

## 자동차 스킨 속도계 디자인

상단 스킨을 **대신남 자동차 모드**로 바꾸면 화면 맨 위에 SPEEDOMETER 창이 나타나고, **디자인**에서 카본 세그먼트(기본), 네온 링, 클래식 아날로그, 미니멀 디지털, 택티컬 그린, 콕핏 PFD를 고를 수 있습니다. 선택한 디자인은 앱을 다시 열어도 유지됩니다. 속도·방향·주행 기록, 속도 경고와 HUD는 GPS 값으로 동작하며, 디자인을 바꿔도 GPS 수신은 끊기지 않습니다.

브라우저에서 GPS 연동과 화면 크기별 표시를 확인하려면 Node.js 22에서 `npm ci`, `npx playwright install chromium`, `npm test`를 차례로 실행합니다. 이 검증은 Android GPS 브리지를 모의하며 실제 기기의 위치 수신 테스트는 별도입니다.

## 차량 핸들 버튼 · 삼성 DeX

내 음악을 재생하면 안드로이드 미디어 세션이 열려, 블루투스로 연결된 차량의 핸들 버튼(다음/이전/재생/일시정지), 블루투스 이어폰, 키보드 미디어 키로 조작할 수 있고 차량 화면에 곡 제목과 앨범 아트가 표시됩니다. 외부 앱 모드에서는 핸들 버튼이 YouTube Music·Spotify로 바로 전달됩니다. DeX로 외부 디스플레이에 띄워도 창 크기에 맞춰 배치가 바뀝니다.

## 두 가지 판

- **DaesinnamAmp.apk (권장)**: 일반 설치용. 외부 앱 연동은 시각화, EQ, 재생/다음/이전 버튼, Spotify 곡 정보(Spotify 설정 → 기기 브로드캐스트 상태 켜기)를 지원합니다.
- **DaesinnamAmp-full.apk**: 알림 접근 권한으로 모든 앱의 곡 정보, 앨범 아트, 탐색까지 지원합니다. 이 권한 때문에 Google Play 프로텍트가 설치를 막을 수 있습니다.

두 판은 같은 앱이라 서로 덮어 설치됩니다.

## APK 만드는 방법 1: GitHub (PC에 아무것도 설치하지 않음)

1. github.com 에 로그인하고 새 저장소(New repository)를 만듭니다. 비공개(Private)여도 됩니다.
2. 저장소 화면에서 **Add file → Upload files**를 누르고, 이 압축을 푼 폴더 안의 **모든 파일과 폴더**를 끌어다 놓은 뒤 **Commit changes**를 누릅니다.
   - `.github` 폴더가 꼭 함께 올라가야 합니다. 숨김 폴더라 안 보이면 파일 탐색기에서 숨김 항목 표시를 켜세요.
3. 저장소의 **Actions** 탭으로 가면 "Build APK"가 자동으로 실행됩니다. 5분 정도 걸립니다.
4. 초록색 체크가 뜨면 그 실행을 눌러 맨 아래 **Artifacts**의 `DaesinnamAmp-apk`를 내려받습니다.
5. 받은 zip 안의 `app-release.apk`를 태블릿으로 옮깁니다.

## APK 만드는 방법 2: Android Studio

1. Android Studio에서 **Open**으로 이 폴더를 엽니다.
2. 메뉴 **Build → Build App Bundle(s) / APK(s) → Build APK(s)**를 누릅니다.
3. `app/build/outputs/apk/` 폴더에 APK가 생깁니다.

## 태블릿에 설치

1. APK 파일을 태블릿에서 엽니다.
2. "출처를 알 수 없는 앱" 경고가 뜨면 **설정 → 이 출처 허용**을 켭니다.
3. 설치 후 알림 권한을 허용하면 알림창과 잠금 화면에서 이전/재생/다음 버튼을 쓸 수 있습니다.

## 참고

- 음악은 **+ 추가** 버튼으로 기기의 파일을 여러 개 한 번에 고릅니다.
- 재생 중에 뒤로 가기를 눌러도 앱이 꺼지지 않고 음악이 계속 나옵니다. 완전히 끄려면 정지 후 뒤로 가기를 누르세요.
- APK는 `signing/amp.keystore`로 서명되어 업데이트 때 덮어 설치됩니다. 저장소가 공개라 이 키도 공개 상태이니, 이 저장소의 Releases가 아닌 곳에서 받은 Daesinnam Amp는 설치하지 마세요. Play 스토어에 올리려면 별도의 비공개 키가 필요합니다.
- 화면 디자인(속도계 포함)은 `app/src/main/assets/index.html` 한 파일에 들어 있습니다.

## 시각화 효과

NOW PLAYING 창의 효과 선택(◀ ▶ 또는 목록)에서 10가지를 고를 수 있습니다: SPECTRUM, MIRROR, SCOPE, AREA(곡선 면), RING(원형 스펙트럼), RADAR(회전 레이더), WAVES(겹친 파형), DOTS(점 매트릭스), PULSE(저음에 퍼지는 원), VU METER(좌우 아날로그 바늘). 화면을 누르면 다음 효과로 넘어가고, 고른 효과는 다시 열어도 유지됩니다. 색은 스킨을 따릅니다.

## 기종별 판 (갤럭시 Z 폴드7 · 폴드8 울트라)

릴리스에 `DaesinnamAmp-GalaxyZFold8Ultra.apk`(일반)와 `DaesinnamAmp-GalaxyZFold8Ultra-full.apk`(전체 기능)가 있습니다. 폴드7과 폴드8 울트라 모두 이 파일을 씁니다. 같은 앱이라 기존 앱 위에 덮어 설치하면 목록·설정이 그대로 남습니다.

- 접었을 때(외부 화면, 약 21:9): 머리글을 한 줄로 줄이고 속도계가 첫 화면을 채웁니다. 가로로 두면 왼쪽에 속도계, 오른쪽에 나머지 창.
- 펼쳤을 때(내부 화면, 거의 정사각형): 왼쪽에 속도계를 고정하고 오른쪽에 조종 패널·관제탑·블랙박스·지도·플레이어를 둡니다. 일반 스킨은 2열.
- 반쯤 접어 세우면(탁상 모드): 접히는 선 위쪽에 속도계.
- 설정 → "폴드 화면 맞춤"에서 끄거나 일반 판에서도 켤 수 있습니다.

## D1 DASHCAM (블랙박스)

자동차 스킨에 **D1 Dashcam** 창이 있습니다. "연결"을 누르면 블랙박스 와이파이(기본: 이름이 `Car-Cam`으로 시작하는 와이파이)에 **이 앱만** 연결하고, 지도·음악 정보 같은 인터넷은 모바일 데이터를 그대로 씁니다. 연결되면 실시간 화면이 나오고, 전체 화면으로 볼 수 있습니다. 화면이 안 나오면 "카메라 찾기"로 블랙박스가 어떤 방식으로 통신하는지 확인할 수 있습니다. 와이파이 이름·비밀번호는 "블랙박스 와이파이"에서 바꿉니다. 녹화 파일 목록·재생은 다음 버전에서 추가합니다.

## 창 순서

설정 → 창 순서에서 지금 스킨에 보이는 창(속도계, 조종 패널, 관제탑, 지도, 플레이어, 재생 화면, 이퀄라이저, 재생 목록)의 순서를 ▲▼로 바꿀 수 있습니다. 콕핏 스킨, 다른 자동차 스킨, 일반 스킨의 순서를 따로 기억하며, "되돌리기"로 기본 배치로 돌아갑니다. 순서를 바꾸면 창이 그 순서대로 놓이고, 2열·가로 한 줄 화면에서는 속도계·조종 패널·관제탑·지도가 한 줄 전체를 차지합니다.

## 콕핏 스킨 속도계 (대신남 PFD)

콕핏 스킨의 SPEEDOMETER는 "대신남 PFD" 디자인 패키지를 씁니다. 위쪽에 최고 속도·평균 속도·주행 거리·주행 시간·고도·GPS 정확도(위성 수), 가운데에 왼쪽 속도 테이프·수평계(지형 배경)·오른쪽 고도 테이프, 아래에 방위 리본과 GPS 켜기·기록 초기화·HUD·표시 방식·수평 맞춤·테마 버튼이 있습니다. 속도·고도·방위·위성은 앱의 GPS, 진행 방향은 나침반, 수평계는 기기 기울기 센서, 주행 기록은 앱의 기록을 그대로 씁니다. 속도 경고 기준은 앱의 속도 경고와 같은 값이며, 15초 넘게 GPS가 갱신되지 않으면 DATA LOST로 표시합니다. (PFD v1.1) 하늘에는 구름이 원근에 따라 실제 속도에 맞춰 지나가고, 지면에는 도심 불빛·가로등이 지나갑니다. 정차·GPS 끊김에서는 멈춥니다. 진행 방향(나침반)이 바뀌면 구름·도심 불빛은 관찰자 둘레로 돌고 별·달·지평선 건물은 옆으로 흘러, 좌우로 선회하는 것처럼 보입니다. (PFD v1.2) 아래쪽 표시 방식 목록에서 **콕핏 PFD**(기본)와 **에어포스**(검은 건메탈 프레임·잘린 모서리·녹색 HUD 계기, 상단 DAESINNAM ONE / AIRFORCE), **심플 HUD**를 고를 수 있습니다. 디자인을 바꿔도 GPS·주행 기록·배경·주야간 설정은 그대로이며, 고른 디자인은 앱이 기억합니다. 야간에는 짙은 하늘에 달·별·어두운 구름이 뜹니다. 테마 "자동"은 오후 7시~오전 6시를 야간으로 합니다. PFD 설정에서 배경 이동 끄기와 품질(높음/균형)을 고를 수 있고, 설정은 앱이 기억합니다. 다른 자동차 스킨에서는 기존 속도계 디자인 6종(구름·밤하늘이 있는 콕핏 PFD 포함)을 그대로 쓸 수 있습니다.

## 파일 구조 (화면)

- `app/src/main/assets/index.html` — 앱 화면 전체(스킨, 창, 플레이어, 조종 패널, 관제탑, 지도 등)
- `app/src/main/assets/pfd/` — 대신남 PFD 패키지 원본(고치지 않음). 새 버전은 이 폴더에 덮어쓰기
- `app/src/main/assets/pfd-amp.js`, `pfd-amp.css` — PFD를 앱에 붙이는 연결 코드와 앱 전용 추가 효과(선회 등)

## 서명 키

APK 서명 키는 저장소에 두지 않고 GitHub 저장소의 Actions 비밀값으로 넣습니다: `AMP_KEYSTORE_BASE64`(PKCS12 키스토어를 base64로), `AMP_KEYSTORE_PASSWORD`, `AMP_KEY_ALIAS`, `AMP_KEY_PASSWORD`. 비밀값이 없으면 CI가 테스트까지만 하고 "서명 키 준비" 단계에서 멈춥니다. 로컬에서 비밀값 없이 빌드하면 서명하지 않은 APK가 나옵니다. v5.8부터 새 키를 쓰므로 그 전 버전을 쓰던 기기는 한 번 지우고 다시 설치해야 합니다.
