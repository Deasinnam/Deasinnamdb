# 회의비서 (갤럭시 폴드용 안드로이드 앱)

회의 시작 때 녹음 버튼을 누르고, 끝나면 "회의 종료 · 분석"을 누르면

- 화자를 구분해 받아쓰고(OpenAI `gpt-4o-transcribe-diarize`)
- 요약, 핵심 내용, 결정 사항, 화자별 발언, **나에게 요청된 일**, 할 일, 남은 질문을 정리하고(GPT)
- 회의에서 정한 일정을 휴대폰 캘린더(구글 계정 → 구글 캘린더 동기화)에 자동으로 넣습니다.

## 처음 설정

1. 설정(⚙)에서 OpenAI API 키를 넣습니다(기기 키 저장소로 암호화해 보관).
2. 내 이름을 넣고, "내 목소리 등록(8초)"을 해 두면 받아쓰기에서 내 발언에 내 이름이 붙어 '나에게 요청된 일'이 정확해집니다.
3. 일정을 넣을 캘린더를 고릅니다(구글 계정 캘린더 권장).

## 구조

- `RecorderService`: 포그라운드 녹음(16kHz WAV, 10분 조각) → 분석까지
- `Pipeline`: 조각별 화자 구분 받아쓰기(앞 조각 화자 목소리를 최대 4명까지 이어 보냄) → GPT 분석 → 캘린더
- `Calendars`: CalendarContract로 일정 넣기·빼기
- `assets/ui`: 화면(접은 화면 1단, 펼친 폴드 2단)

`gpt-4o-transcribe-diarize`는 OpenAI가 2027-02-26 제공 종료를 예고했습니다. 설정 › 고급에서 모델을 바꿀 수 있습니다.
