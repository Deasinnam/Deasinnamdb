# 덜씀 (갤럭시)

맥용 덜씀을 갤럭시로 옮긴 앱. 메모리 · 저장공간 · 배터리를 **버튼 하나로 덜 쓰게** 합니다.
무엇을 정리할지는 체크 상자로 직접 고릅니다. 인터넷 권한이 없고, 정리는 모두 휴대폰 안에서만 합니다.

- **메모리 덜씀**: 30분 넘게 안 쓴 앱 종료(사용 기록 접근 · Shizuku면 완전 종료) + 화면에 없는 앱의 남은 메모리 정리
- **저장공간 덜씀**: 모든 앱 캐시(Shizuku `pm trim-caches`) · 다운로드 폴더 APK · 사진 · 동영상 휴지통
- **배터리 덜씀**: 전원을 뽑으면 절전 모드(Shizuku) · 화면 밝기 낮춤(시스템 설정 변경), 꽂으면 원래대로 — 덜씀 지킴이(알림)
- **오래된 갤럭시 가볍게**: 애니메이션 0.5배(Shizuku) · 메모리 '주의'면 1시간 넘게 안 쓴 앱 자동 정리
- 메모리 사용률 · 상태(정상 · 주의 · 위험) · 최근 2분 그래프

빌드: `deolnureum-sseum` 브랜치에 올리면 GitHub Actions가 에뮬레이터 점검 후 서명해 `sseum-latest` · `sseum-v<버전>` 릴리스에 올립니다.
