# 덜누름 데스크 (안드로이드)

안드로이드를 데스크톱처럼 쓰는 홈 앱(런처)입니다. 바탕화면·작업 표시줄·시작 메뉴·창으로 이루어진 구성을 따르되, 모양은 덜누름 고유의 것입니다.

- **바탕화면**: 자주 쓰는 앱과 도구를 아이콘으로, 다른 앱의 **위젯**을 올려 옮기고 크기 바꾸기
- **작업 표시줄**: 아이콘을 가운데(또는 왼쪽)에 두는 반투명 막대. "덜" 시작 단추, 고정한 앱, 열려 있는 창·최근 연 앱, 연결·배터리(빠른 설정), 시계(달력), 맨 오른쪽 바탕화면 보기
- **시작 메뉴**: 화면 가운데에 뜨며, 앱 찾기 · 고정됨 · 추천(최근 연 앱) · 모든 앱(ㄱㄴㄷ 순)
- **창**: 앱을 자유 창·왼쪽 반·오른쪽 반·전체 화면으로 열기 (기기가 자유 창을 지원할 때).
  내부 도구(메모·계산기·달력·설정)는 끌어 옮기고 크기를 바꾸고, 가장자리에 붙이거나 최대화 단추로 배치(반·반, ⅔·⅓, 전체)를 고를 수 있는 창
- **배경**: 기본 배경 5가지 또는 내 사진 · 어두운/밝은 색 · 작업 표시줄을 붙임/떠 있는 모양
- 인터넷 권한 없음. 앱 목록과 설정은 기기 안에만 둡니다.

구조: `MainActivity.java`(앱 목록·아이콘·앱 띄우기·위젯·배경) + `assets/ui/`(화면, WebView).
뷰는 아래부터 배경 → 위젯 → 바탕화면 화면(투명) 세 겹입니다.
빌드: GitHub Actions(브랜치 `deolnureum-desk`) → 에뮬레이터 자동 점검 → Releases `desk-latest`.
