# 덜누름 브라우저

언제나 PC 화면으로 여는 가벼운 안드로이드 브라우저 (옛 이름: 대신남 PC 브라우저).

- PC용 사용자 에이전트 + 넓은 화면 폭(1024~1920) 고정, 유튜브는 PC 화면 주소로
- HTTPS 전용 · 인증서 오류/유해 사이트/로컬 파일/외부 앱 링크 차단 · 제3자 쿠키 차단
- 위쪽은 주소 줄 한 줄(40dp), 진행 표시는 화면 위에 겹쳐 그림
- 화면 회전·접기·창 크기 변경(DeX)에도 페이지를 다시 불러오지 않음
- 파일 받기: 확인 후 휴대폰 "다운로드" 폴더에 저장 (일반 파일 · 사이트가 만들어 주는 파일 · 이미지 길게 눌러 저장), 한글 파일 이름 지원
- 유튜브 스튜디오 · 구글 로그인: 구글이 WebView 앱 안의 로그인을 막으므로 크롬에서 엶 (위쪽 "스튜디오" 단추)
- 아래쪽 ◀ ▶: 페이지가 다 뜨기 전에 여러 번 눌러도 한 칸씩만 이동 (첫 페이지·마지막 페이지에서는 알림)
- 탭: 최대 10개 (아래쪽 "탭" 단추, 링크 길게 누르기 → 새 탭에서 열기). 앱을 다시 열면 보던 탭을 이어서 보여 줌
- 페이지 안에서 찾기 · 방문 기록(최근 100개) · "이 페이지 크롬에서 열기" (증권·결제처럼 막히는 사이트용)
- 앱 설치 파일(APK)은 받기 전에 따로 경고, 받는 파일은 확인 창에 보여 준 이름 그대로 저장
- 설정: 화면 보호(최근 앱 미리보기·캡처 막기), 닫을 때 웹 데이터 삭제
- 키보드 단축키: Ctrl+L, F5/Ctrl+R, Alt+←/→, Ctrl+T/W/Tab(탭), Ctrl+F(찾기), Ctrl+H(방문 기록), Ctrl+D, Ctrl+J(받은 파일)

빌드: `deolnureum-browser` 브랜치에 올리면 GitHub Actions가 APK를 만들어 Releases(`browser-latest`)에 올립니다.
