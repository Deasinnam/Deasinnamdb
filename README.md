# 덜누름 TV (안드로이드)

DeX로 연결한 (터치) 모니터를 **스마트 TV 홈**처럼 씁니다.
넷플릭스 · 웨이브 · 티빙 · 유튜브 · 스포티파이를 큰 타일에서 골라 **전체 화면**으로 엽니다.

## 0.1 기능

- **홈**: 고른 서비스의 큰 배너(9초마다 넘어감, 옆으로 밀어 넘기기) · 내 서비스 타일 · 다른 영상 · 음악 앱 줄
- **열기**: 이 화면(TV로 쓰는 모니터)에서 전체 화면으로 (`ActivityOptions` 창 방식 1), 설치 안 된 서비스는 Play 스토어 페이지
- **리모컨처럼**: 터치 · 마우스 · 키보드 방향키 / Enter / Esc, 포커스 테두리
- **편집**: 타일을 길게 누르기(또는 오른쪽 클릭) → 앞뒤로 옮기기 · 빼기, [+ 서비스 추가]
- **위쪽 막대**: 시계 · 볼륨(−/+/끌기/휠/음소거) · 설정, DeX에서 창으로 떠 있으면 [전체 화면] 단추
- **설정**: 앱을 전체 화면으로 열기, 시스템 막대 숨기기, 화면 보호기(끄기 · 3 · 10 · 30분, 시계가 천천히 자리를 옮김)
- 권한: 진동만. 인터넷 권한 없음(영상은 각 앱이 재생). 설정은 기기 안에만 저장

## 구조 · 빌드

- `MainActivity.java`: WebView 화면 + 앱 목록 · 아이콘 · 앱 열기 · 스토어 · 볼륨 · 전체 화면 (`window.TV`)
- `assets/ui/`: 화면 (`tv.js`는 브라우저에서 열면 가짜 `TV`로 화면만 시험할 수 있음)
- GitHub Actions(브랜치 `deolnureum-tv`) → 에뮬레이터 점검 → 서명(`AMP_KEYSTORE_*`, 다른 덜누름 앱과 같은 키) → Releases `tv-latest` · `tv-v<버전>`
