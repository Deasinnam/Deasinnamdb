# 대신남 로드 디펜스

탑 로드(Top Lords) 스타일의 안드로이드 다리 방어 게임입니다.

- 화면을 좌우로 끌어 영웅을 움직입니다.
- 영웅은 자동으로 화살을 쏩니다. 게이트를 맞히면 숫자가 커지고(+1씩, ×게이트는 6발마다 +1), 적을 맞히면 적 수가 줄어듭니다.
- 게이트를 지나면 병력이 늘어나고(+, ×) 빨간 게이트는 병력이 줄어듭니다.
- 영웅 부대가 적 부대와 부딪히면 병력끼리 싸웁니다. 놓친 적은 성벽을 공격합니다.
- 스테이지 끝에는 보스가 나옵니다. 성벽 체력이 0이 되면 패배.
- 전투 화면은 영웅 뒤에서 다리를 내려다보는 3D 원근 시점입니다.
- 스테이지 사이에는 영지(대신남 왕국) 화면이 나옵니다. 골드로 건물을 짓고 강화합니다.
  - 성: 성벽 체력 / 병영: 시작 병력 / 궁수 훈련소: 화살 피해 / 대장간: 연사 속도 / 마법탑: 멀티샷 / 금광: 보상 골드
- 진행 상황은 자동 저장됩니다.

## 구조
- `app/src/main/assets/game.html` — 게임 전체(HTML5 캔버스, 외부 라이브러리 없음)
- `app/src/main/java/com/daesinnam/lords/MainActivity.java` — 전체 화면 WebView, 진동, 뒤로가기 처리
