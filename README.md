# 덜누름 노트 (안드로이드)

S펜으로 쓰는 필기 노트입니다. 갤럭시 탭 · 폴드 · DeX에서 씁니다.

- **펜 · 형광펜 · 지우개**: 펜은 필압에 따라 굵기가 바뀝니다. 색 6가지(형광펜 5가지), 굵기 3단계
- **S펜 버튼으로 지우개**: 펜 옆 버튼을 누른 채 쓰면 언제든 지우개 (닿은 획을 통째로 지움)
- **손바닥 막기**: S펜을 한 번 쓰면 "펜으로만 쓰기" — 손가락은 화면 옮기기 · 두 손가락 확대, 옆으로 밀면 쪽 넘기기
- **종이**: 줄 · 모눈 · 점 · 무지, 쪽 추가 · 지우기 · 쪽으로 가기
- **PDF 위에 쓰기**: "PDF 열기" 또는 다른 앱에서 "덜누름 노트로 열기 · 보내기"
- **내보내기**: 이 쪽을 그림(PNG, 너비 2000), 노트 전체를 PDF(필기는 선으로)
- **되돌리기 · 다시 하기**(쪽을 넘겨도 기억), 자동 저장
- DeX · 키보드: 마우스로 쓰기, 휠로 위아래, Ctrl+휠 확대, Ctrl+Z / Ctrl+Y, P · H · E로 도구, PageUp/Down 쪽
- 권한 없음 · 인터넷 없음. 노트는 앱 저장소 `files/notes/<id>/`(note.json · thumb.png · source.pdf)에만 둡니다.

구조: `ListActivity`(목록) · `NoteActivity`(필기 화면) · `InkView`(입력 · 그리기) · `Ink`(획 모양 · 종이) · `Model`(쪽 단위 좌표: 너비 1000) · `Store` · `Pdf`(PdfRenderer) · `Exporter`(PNG · PdfDocument) · `SelfTest`(시험용 빌드 자동 점검).
빌드: GitHub Actions(브랜치 `deolnureum-note`) → 에뮬레이터 자동 점검(실제 스타일러스 입력) → Releases `note-latest`.
