# 덜누름 게임 (안드로이드)

게임과 게임 앱, 게임 도구를 한곳에 모은 허브 앱입니다. 덜누름이 직접 만든 앱이며, 다른 게임 앱은 **원작 그대로** 공식 배포처로 안내하고 실행만 합니다(다시 배포하지 않음). 에뮬레이터는 다루지 않습니다.

## 0.1에 들어간 것

- **화면**: 휴대용 게임기 스타일 — 어두운 남색 바탕, 홈(큰 화면 + 최근 플레이 · 게임 앱 · 빠른 도구 선반) / 라이브러리 / 게임 앱 / 도구. 게임패드·방향키로 움직임(A 선택 · B 뒤로 · Y 게임 설정 · L1/R1 탭), 아래에 버튼 안내 줄

- **게임**: 기기에 설치된 게임(안드로이드 "게임" 분류)을 자동으로 모음. "+ 게임 추가"로 직접 넣고 빼기. 누르면 게임 최적화(설정한 경우)를 켜고 바로 시작
- **게임 앱**: DroidDeck(스팀·배틀넷 등 PC 게임), Moonlight, Steam Link, Steam, Xbox Game Pass. 설치돼 있으면 열기, 없으면 공식 배포처로
- **게임 녹화**: 안드로이드 화면 녹화(MediaProjection) → H.264 MP4, 마이크 소리 선택. 저장 위치 `동영상/덜누름 게임`. 알림의 "녹화 멈추기"
- **게임 최적화 · 기기 맞춤 설정**: 칩(SoC)·메모리·최대 주사율·발열·배터리 온도·절전 모드를 보고 단계(가볍게/균형/고성능)를 추천. 단계마다 FPS 상한·게임 해상도·게임 모드·녹화 화질이 정해짐. 기본값과 게임별 값(게임을 길게 누름)을 따로 저장. 녹화 화질은 바로 적용, FPS 상한·해상도·게임 모드는 고급 기능(Shizuku) 연결 뒤 적용(`Optimizer.shellCommands`)
- **게임하는 동안**: 방해 금지(돌아오면 꺼짐), 삼성 게임 부스터 바로 열기
- **키 매핑**: 게임패드·키보드 버튼 → 게임 화면의 정해 둔 자리 누르기(접근성 서비스 `KeymapService`, 화면 내용은 읽지 않음). 게임별로 켜고, 게임 화면 왼쪽 위 🎮 → 빈 곳 눌러 자리 → 패드 버튼으로 연결, 톡/꾹(누르는 동안) 바꾸기·옮기기·지우기. 아날로그 스틱·동시 누르기는 다음 단계
- **화면 주사율**: 지금 주사율과 지원 주사율

## 다음 단계

- 게임 중 떠 있는 단추(녹화·FPS·최적화 바로 켜기)
- 고급 기능(Shizuku) 연동: 맞춤 설정의 FPS 상한·해상도·게임 모드 실제 적용, 실제 FPS, 안드로이드 게임 성능 모드(`cmd game mode performance`), CPU·GPU 사용량
- 녹화에 게임 소리(내부 소리) 넣기

## 구조

```
MainActivity   WebView 화면(assets/ui/) + Bridge: 앱 목록·아이콘, 실행, 방해 금지, 주사율
Optimizer      기기 분석 → 추천 단계·설정값, 게임별 저장, Shizuku용 명령 만들기
KeymapService  키 매핑(접근성): 버튼 받기 → 화면 누르기, 게임 위 🎮 단추·편집 화면
RecordService  화면 녹화 서비스(포그라운드), MediaStore에 MP4 저장
```
