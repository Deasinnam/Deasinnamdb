# 덜누름 PC 런처 (안드로이드)

삼성 DeX가 없는 일반 안드로이드 휴대폰도 **외부 모니터에 꽂아 PC처럼** 쓰게 하는 앱입니다.
모니터에는 바탕화면 · 작업 표시줄 · 시작 메뉴 · 창 · 위젯(덜누름 데스크 1.6.7과 같은 화면)을 띄우고,
휴대폰 화면은 연결 도우미와 **터치패드 · 키보드**가 됩니다.

## 되는 조건

1. **휴대폰이 USB-C 영상 출력(DisplayPort Alt Mode)을 지원**해야 합니다. 꽂았을 때 폰 화면이 모니터에 나오면 됩니다. 없으면 앱으로 해결할 수 없습니다(무선 미러링만 가능).
2. **데스크톱 모드** (개발자 옵션 "보조 디스플레이에서 데스크톱 모드 강제 사용" + "자유 형식 창 사용", 다시 시작) — 모니터가 폰과 따로인 화면이 되고 다른 앱도 모니터에서 창으로 열립니다. Shizuku가 있으면 앱에서 바로 켜고 다시 시작까지 합니다. 꺼져 있으면 기기에 따라 PC 화면은 열려도 다른 앱이 폰에서 열릴 수 있습니다.
3. 터치패드 · 폰 키보드는 **안드로이드 11 이상** + 접근성에서 "덜누름 PC 런처 터치패드" 켜기.

픽셀 · 삼성 최신 기기는 안드로이드 16 QPR3부터 연결 디스플레이 데스크톱이 기본으로 있어, 덜누름 PC 런처는 그 위에서 바탕화면 · 시작 메뉴 역할을 합니다.

## 구성

| 화면 · 부분 | 하는 일 |
|---|---|
| `PhoneActivity` + `assets/phone/` | 앱 아이콘. 모니터 연결 상태(이름 · 해상도 · 데스크톱 모드 여부), "모니터에 PC 화면 열기", 처음 한 번 준비 4단계, 터치패드 |
| `MainActivity` + `assets/ui/` | 모니터의 PC 화면(덜누름 데스크에서 가져옴). 앱을 열면 **그 모니터에** 창 · 반쪽 · 전체 화면으로. `SECONDARY_HOME`도 걸어 둠 |
| `Monitor` | 외부 화면 찾기(발표용 화면 우선), 데스크톱 모드 설정 읽기 · Shizuku로 켜기, 화면 지정해 열기 |
| `MonitorService` | 켜 두면 모니터를 꽂자마자 PC 화면을 엶. 안드로이드가 막으면 알림의 "모니터에 열기"로 (터치패드가 켜져 있거나 "다른 앱 위에 표시" 허용이면 바로 열림) |
| `PointerService` (접근성) | 모니터에 포인터를 그리고(다른 화면 덮개 창), 클릭 · 길게 누르기(오른쪽 클릭) · 끌기(이어지는 제스처) · 넘기기를 그 화면에 전달(화면 지정 제스처, 안드로이드 11+). 폰 키보드 글자를 모니터에서 입력 중인 칸에 넣음 |
| `Shizu` | Shizuku 연결 (데스크톱 모드 켜기 · 다시 시작 · 창정리) |

터치패드 조작: 한 손가락 이동, 톡 = 클릭, 길게 = 오른쪽 클릭, 두 번 톡 하고 끌기 = 끌기, 두 손가락 = 넘기기, 속도 조절, 빠르게 움직이면 가속.

## 빌드 · 점검

GitHub Actions(브랜치 `deolnureum-pc`) → 에뮬레이터 점검 → Releases `pc-latest`(버전별 `pc-v<버전>`), 점검 기록은 `pc-ci`.
에뮬레이터 점검 2부는 안드로이드 가상 두 번째 화면(`overlay_display_devices`)을 모니터 삼아
모니터 찾기 · 모니터에 PC 화면 열기 · 거기서 띄운 앱이 모니터에 뜨는지 · 포인터 이동 · 클릭 · 끌기 · 폰 키보드 입력을 확인합니다.
서명 키는 다른 대신남 앱과 같습니다(`AMP_KEYSTORE_*`). 인터넷 권한 없음.
