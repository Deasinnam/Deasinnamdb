# 덜누름 벤치 (com.daesinnam.bench)

0.2.0: AI 보이스 자비스는 Chat DNR Ai 0.6.1+의 벤치 입구(com.daesinnam.ai.action.BENCH)로 직접 잼 — 모델 올리기 · 첫 글자 · 초당 토큰 · 질문 읽기 · 목소리 만들기 · 받아 적기(정확도) · 그림 1장. 없으면 기본 측정.

덜누름 앱들이 하는 실제 작업을 이 기기에서 돌려 "PC처럼 어디까지 되나"를 10,000점 만점으로 보여 주는 앱.

- 분야 9개(문서 · 사진 · 오디오 · 데스크탑 · 영상 · 브라우저 · 게임 · AI 보이스 자비스 · 스피드미터), 비중은 문서 · 영상 15%, 나머지 10%
- 전체 측정 = 9개 분야 + 10분 연속 부하(성능 유지율 · 배터리 온도 · 배터리 감소)
- 화면 · 점수 기준표: `app/src/main/assets/ui/bench.js` (ITEMS = 항목별 기준값, v0.1 임시)
- 기기 측정: `Tests.java` (PDF · 표 · 줄 나누기 · 2400만 화소 보정 · JPEG · 오디오 믹싱 · H.264 인코딩 · 행렬 곱 · 센서)
- 인터넷 · 위치 · 마이크 권한 없음. 결과는 기기 안에만 저장
- 사이트에는 아직 올리지 않음: 이 가지에 push하면 `bench-preview` 미리보기 릴리스(관리자 시험용)만 갱신
