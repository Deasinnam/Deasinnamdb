# 덜누름 패드 (안드로이드)

DeX(또는 외부 모니터)에 연결한 동안 **휴대폰 화면을 버튼 판**으로 쓰는 앱입니다.
버튼을 누르면 고른 앱이 **큰 화면(DeX)** 에서 열립니다. 큰 화면이 연결되어 있지 않으면 지금 화면에서 엽니다.

## 0.1 기능

- **버튼 판(탭)**: 처음 열면 설치된 앱으로 기본 판을 만듭니다 — 자주 쓰는 앱 · 문서 · 업무 · 인터넷 · 소통 · 미디어 · 게임
- **앱 열기**: 버튼을 누르면 큰 화면에서 열기(`ActivityOptions.setLaunchDisplayId`), 짧은 진동
- **편집**: 버튼을 길게 누르거나 [편집] → 앱 바꾸기 · 이름 · 색(7가지) · 순서 · 지우기, [+ 버튼 추가], 판 추가 · 이름 · 순서 · 지우기, 기본 판으로 되돌리기
- **큰 화면 표시**: 큰 화면에 연결되면 "큰 화면에 연결됨". 패드가 DeX 쪽에 떠 있으면 "휴대폰 화면으로 옮기기"
- **화면 켜 두기**: 큰 화면에 연결된 동안 휴대폰 화면이 꺼지지 않게(메뉴에서 끌 수 있음)
- 권한: 진동만. 인터넷 권한 없음. 버튼 판은 기기 안에만 저장

다음 버전 후보: 단축키 보내기(Shizuku), 문구 입력, 앱마다 판 자동 전환.

## 구조

- `MainActivity.java`: WebView 화면 + 앱 목록 · 아이콘 · 앱 열기 · 화면(디스플레이) 정보 · 저장 (`window.Pad`)
- `assets/ui/`: 화면 (`pad.js`는 브라우저에서 열면 가짜 `Pad`로 화면만 시험할 수 있음)

## 빌드 · 배포

GitHub Actions(브랜치 `deolnureum-pad`) → 에뮬레이터 점검(보조 디스플레이 시뮬레이션으로 "큰 화면" 흉내: 기본 판 · 저장 · 설정 앱이 두 번째 화면에 뜨는지)
→ 서명(저장소 비밀값 `AMP_KEYSTORE_*`, 다른 덜누름 앱과 같은 키) → Releases `pad-latest` · `pad-v<버전>`.
버전은 `app/build.gradle`의 `versionCode`/`versionName`.
