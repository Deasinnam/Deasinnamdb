# 덜누름 데스크 (안드로이드)

안드로이드를 데스크톱처럼 쓰는 홈 앱(런처)입니다. 1.4부터 윈도우 11과 같은 배치·치수·재질을 따릅니다(작업 표시줄 48, 시작 메뉴 642×726, 빠른 설정 360 등). 윈도우 로고·마이크로소프트 아이콘·배경 그림은 쓰지 않고 직접 그린 아이콘과 "덜" 시작 단추를 씁니다.

- **바탕화면**: 자주 쓰는 앱과 도구를 아이콘으로, 다른 앱의 **위젯**을 올려 옮기고 크기 바꾸기
- **작업 표시줄**: 왼쪽 위젯, 가운데 "덜" 시작 · 검색 상자 · 작업 보기 · 고정한 앱·열린 창, 오른쪽 연결·음량·배터리(빠른 설정), 시계(달력), 바탕화면 보기
- **시작 메뉴**: 검색(가장 일치하는 항목 + 자세히), 고정됨(6×3 쪽 넘김), 추천(최근 연 앱과 시각), 모든 앱(ㄱㄴㄷ 순), 사용자·전원 단추
- **빠른 설정**: 와이파이·블루투스·비행기 모드·절전 모드·손전등·접근성 타일, 밝기·음량 막대(밝기는 "시스템 설정 변경" 허용 시)
- **작업 보기**, 윈도우 키 단축키(⊞ 시작, ⊞+D/A/N/S/Tab, ⊞+←/→/↑ 창 붙이기), 강조색 5가지
- **창**: 앱을 자유 창·왼쪽 반·오른쪽 반·전체 화면으로 열기 (기기가 자유 창을 지원할 때).
  내부 도구(메모·계산기·달력·설정)는 끌어 옮기고 크기를 바꾸고, 가장자리에 붙이거나 최대화 단추로 배치(반·반, ⅔·⅓, 전체)를 고를 수 있는 창
- **배경**: 기본 배경 5가지 또는 내 사진 · 어두운/밝은 색 · 작업 표시줄을 붙임/떠 있는 모양
- 인터넷 권한 없음. 앱 목록과 설정은 기기 안에만 둡니다.

구조: `MainActivity.java`(앱 목록·아이콘·앱 띄우기·위젯·배경) + `assets/ui/`(화면, WebView).
뷰는 아래부터 배경 → 위젯 → 바탕화면 화면(투명) 세 겹입니다.
빌드: GitHub Actions(브랜치 `deolnureum-desk`) → 에뮬레이터 자동 점검 → Releases `desk-latest`.
