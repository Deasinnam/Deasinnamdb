# 이음오피스 안드로이드판 (비공식)

[IeumOffice](https://github.com/pblsketch/ieumoffice) 0.12.12를 안드로이드에서 쓸 수 있게 옮긴 앱입니다.

- 한글(HWP·HWPX), 마크다운, HTML: 열기·편집·저장
- PDF: 보기
- 파일 관리자·메신저에서 "이음오피스로 열기" 지원

APK는 [Releases → ieumoffice-latest](../../releases/tag/ieumoffice-latest)에서 받습니다.
구조와 업데이트 방법은 [docs/HANDOFF.md](docs/HANDOFF.md)를 보세요.

(`app/src/main/assets/www/licenses/` 참고).
