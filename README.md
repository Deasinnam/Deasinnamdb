# 덜누름 데스크 (안드로이드)

안드로이드를 데스크톱처럼 쓰는 홈 앱(런처)입니다. 디자인은 덜누름 고유의 것입니다.

- **바탕화면**: 자주 쓰는 앱과 도구를 아이콘으로
- **작업 표시줄**: 시작 버튼, 고정한 앱, 열려 있는 창·최근 연 앱, 연결·배터리·시계
- **시작 메뉴**: 앱 찾기, 고정한 앱, 모든 앱
- **창**: 앱을 자유 창·왼쪽 반·오른쪽 반·전체 화면으로 열기 (기기가 자유 창을 지원할 때),
  내부 도구(메모·계산기·달력·설정)는 끌어 옮기고 크기를 바꾸고 가장자리에 붙일 수 있는 창
- 인터넷 권한 없음. 앱 목록과 설정은 기기 안에만 둡니다.

구조: `MainActivity.java`(앱 목록·아이콘·앱 띄우기·상태) + `assets/ui/`(화면).
빌드: GitHub Actions(브랜치 `deolnureum-desk`) → 에뮬레이터 점검 → Releases `desk-latest`.
