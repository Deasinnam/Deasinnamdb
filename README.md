# 덜누름 게임 (안드로이드)

게임과 게임 앱, 게임 도구를 한곳에 모은 허브 앱입니다. 덜누름이 직접 만든 앱이며, 다른 게임 앱은 **원작 그대로** 공식 배포처로 안내하고 실행만 합니다(다시 배포하지 않음). 에뮬레이터는 다루지 않습니다.

## 0.1에 들어간 것

- **게임**: 기기에 설치된 게임(안드로이드 "게임" 분류)을 자동으로 모음. "+ 게임 추가"로 직접 넣고 빼기. 누르면 게임 최적화(설정한 경우)를 켜고 바로 시작
- **게임 앱**: DroidDeck(스팀·배틀넷 등 PC 게임), Moonlight, Steam Link, Steam, Xbox Game Pass. 설치돼 있으면 열기, 없으면 공식 배포처로
- **게임 녹화**: 안드로이드 화면 녹화(MediaProjection) → H.264 MP4, 마이크 소리 선택. 저장 위치 `동영상/덜누름 게임`. 알림의 "녹화 멈추기"
- **게임 최적화**: 게임하는 동안 방해 금지(돌아오면 꺼짐), 삼성 게임 부스터 바로 열기
- **화면 주사율**: 지금 주사율과 지원 주사율

## 다음 단계

- 게임 중 떠 있는 단추(녹화·FPS·최적화 바로 켜기)
- Shizuku 연동: 실제 FPS, 안드로이드 게임 성능 모드(`cmd game mode performance`), CPU·GPU 사용량
- 녹화에 게임 소리(내부 소리) 넣기

## 구조

```
MainActivity   WebView 화면(assets/ui/) + Bridge: 앱 목록·아이콘, 실행, 방해 금지, 주사율
RecordService  화면 녹화 서비스(포그라운드), MediaStore에 MP4 저장
```

## 빌드 (GitHub Actions, 브랜치 `deolnureum-game`)

화면 코드 문법 확인 → 시험용 APK → 에뮬레이터 점검(`tools/emulator_selftest.sh`: 게임 목록·게임 추가·게임 앱·도구·녹화·다른 앱 실행) → 점검 기록 `game-ci` → 서명한 APK를 Releases `game-latest`에 올림.
