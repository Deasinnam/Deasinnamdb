앱이 공개되면 이렇게 설치합니다. 플레이 스토어 밖에서 받는 앱이라 처음 한 번은 설치 허용이 필요합니다.

STEP 1

APK 내려받기

휴대폰에서 원하는 앱의 내려받기를 누릅니다. 브라우저가 파일을 받습니다.

STEP 2

설치 허용

받은 파일을 열면 "출처를 알 수 없는 앱" 안내가 나옵니다. 설정에서 그 브라우저의 설치를 허용합니다.

STEP 3

설치와 업데이트

설치를 누르면 끝입니다. 새 버전은 같은 방법으로 받아 덮어 설치하면 기록이 그대로 남습니다.

덜누름의 앱은 같은 서명 키로 서명합니다. 서명이 다른 파일을 덮어 설치하라는 안내가 나오면 설치하지 마세요. 앱의 소스와 빌드 기록은 GitHub 저장소 Deasinnam/Deasinnamdb에서 볼 수 있습니다.

CRUISE · 주간 순항

빨리 달리면
구름도 빨리 지나갑니다.

속도가 오르면 하늘의 구름과 발아래 들판이 그만큼 빠르게 스쳐 갑니다. 시속 120km를 넘기면 화면 전체가 붉게 바뀌고 관제탑이 감속을 알립니다.

  • 01실제 속도에 맞춰 흐르는 구름과 지형
  • 02과속 카메라 앞에서 제한 속도와 남은 거리 안내
  • 03시속 120km 초과 시 화면 가득 SLOW DOWN 경고
  • 04머리글에 관제탑(TWR) 한 줄 알림
NIGHT · 야간 비행

해가 지면
밤하늘을 납니다.

밤에는 하늘이 달과 별, 멀리 도시 불빛으로 바뀌고 원형 지도도 어두운 색으로 넘어갑니다. 계기판을 벗어나지 않고 라디오와 음악을 듣습니다.

  • 01주간 · 야간 하늘 자동 전환, 야간용 원형 지도
  • 02FM 라디오: 주파수 다이얼, 이전 · 다음 방송, 즐겨찾기 6칸
  • 03오디오: 다른 앱에서 재생 중인 곡을 시각화와 함께
  • 04아래 메뉴 한 번으로 스피드미터 · 라디오 · 오디오 전환

갤럭시 Z 폴드 펼친 화면에서 찍은 실제 화면

SOUND · 이퀄라이저 · 스트리밍 · 라디오

소리까지
조종석에서.

달리는 동안 듣는 소리도 계기판 안에서 고릅니다. 이퀄라이저로 취향을 맞추고, 스트리밍 음원에 시각화를 입히고, 끊기지 않는 디지털 라디오를 듣습니다.

COCKPIT CONTROL 패널을 크게 본 실제 화면

COCKPIT CONTROL · 조종석 스위치

자주 쓰는 조작은
스위치 하나로.

볼륨, 녹화, 비상 전화, 음소거, 주야간 전환을 조종석 패널 한 줄에 모았습니다. 메뉴를 찾아 들어가지 않고 스위치 한 번으로 끝냅니다.

  • 01미디어 볼륨 다이얼을 돌려 음량을 맞춥니다
  • 02주행 녹화 스위치를 올리면 블랙박스처럼 녹화가 시작되고, 내리면 영상이 저장됩니다
  • 03EMERGENCY 덮개를 열고 SOS를 누르면 미리 지정한 사람에게 바로 전화를 겁니다
  • 04미디어 음소거 스위치 한 번으로 소리를 끕니다
  • 05주간 · 야간 활주로의 낮과 밤이 바뀌고 기기 밝기도 함께 조정됩니다
태양광 무선 후방 카메라

DASHCAM · 후방 카메라

뒤쪽도
계기판 안에서.

태양광 패널로 충전하는 무선 후방 카메라와 연동합니다. 선을 깔 필요 없이 와이파이로 연결하면, 카메라 영상이 폴드 화면에 실시간으로 들어옵니다.

  • 01태양광 패널 무선 후방 카메라와 와이파이로 직접 연결
  • 02DASHCAM 패널에서 실시간(LIVE) 영상 보기
  • 03전체 화면 버튼 한 번으로 화면 가득 크게
  • 04카메라에 연결한 동안에도 지도와 음악은 모바일 데이터로 그대로
CONTROL DECK · 물리 단축 버튼

화면 터치 없이
모든 기능을.

스트림 덱 호환 기기를 연결하면 물리 단축 버튼이 자동으로 채워집니다. 운전 중에 화면을 찾아 누르지 말고, 손끝의 버튼으로 모든 기능을 작동해 보세요.

  • 01음악 이전 · 재생 · 다음 · 전환 · 음소거
  • 02화면 속도계 · 지도 · 라디오 · NOW · 전체
  • 03주행 녹화 · 주야간 · T맵 · 네이버 지도 · 착륙
  • 04버튼마다 그림과 이름이 자동으로 표시됩니다
DIAL · 다이얼 컨트롤러

다이얼 하나로
볼륨부터 기능까지.

다이얼 컨트롤러를 연결하면 볼륨은 돌려서 맞추고, 기본 기능 7가지까지 손을 떼지 않고 모두 조작할 수 있습니다.

  • 01다이얼을 돌려 볼륨 조절
  • 02기본 기능 7가지를 다이얼과 버튼으로 실행
  • 03버튼 덱과 함께 쓰면 화면을 볼 일이 더 줄어듭니다

실제 화면 · 내비게이션 칸은 위치가 드러나지 않게 흐리게 처리

SPLIT · T맵과 함께

T맵을 켜도
계기판은 그대로.

T맵 버튼을 누르면 화면을 나눠 내비게이션을 띄우고, 앱은 남은 칸에 맞춰 스스로 정리됩니다. 길 안내를 보면서 라디오와 음악, 계기판을 오갑니다.

  • 01T맵 버튼 한 번으로 화면 나누기
  • 02가운데 막대를 끌어 두 칸의 비율 조절
  • 03좁은 칸에 맞춘 세로 배치로 자동 정리
  • 04길 안내 옆에서 오디오 · 라디오 · 스피드미터 전환
APPROACH · 착륙

도착하면
활주로에 내립니다.

목적지가 가까워지면 접근 단계로 바뀌어 남은 거리와 고도를 알려 줍니다. 활주로가 다가오고, 터치다운 뒤 도착을 알립니다.

  • 01APPROACH: 자동 착륙까지 남은 거리와 고도 안내
  • 02들판 위로 활주로가 다가오는 착륙 화면
  • 03TOUCHDOWN 감속 뒤 ARRIVED “목적지에 도착했어요”
  • 04착륙 버튼으로 시작, 복행 버튼으로 취소
